    Cara pakai
    1. Buka di Google Chrome (desktop) atau Edge. Izinkan akses mikrofon.
    2. Pasangkan IEM Bluetooth dan jadikan perangkat keluaran default di sistem. Suara terjemahan selalu keluar lewat output default.
    3. Gunakan mikrofon laptop/HP atau mic eksternal, bukan mic headset Bluetooth, supaya audio IEM tidak turun ke mode telepon.
    4. Mode Cepat memotong ucapan per frasa agar suara keluar sambil pembicara masih bicara. Mode Akurat menunggu kalimat selesai.
    5. Offline: saat masih ada internet, tekan Siapkan offline. Paket suara dan model terjemahan untuk kedua arah bahasa akan diunduh. Semua baris bertanda ✓ berarti siap dipakai tanpa internet.
    6. AI Interpreter: buat kunci API gratis di aistudio.google.com (menu Get API key), tempel di kolom kunci, pilih IEM di "Perangkat keluaran", lalu tekan Mulai. Bahasa pembicara dikenali otomatis.
    7. Di smartphone, buka lewat alamat https di Chrome (Android) atau Safari (iPhone). Pemrosesan offline umumnya baru tersedia di Chrome desktop.
